# Artisan Bridge

Build a polished Smart India Hackathon demonstration prototype named “SHILPSETU: AI-Powered Offline Business Manager for Indian Artisans.” This must not feel like a generic marketplace. Create a mobile-first, highly usable artisan dashboard with sign-up/onboarding requiring name and phone number, language selection (show 10+ Indian languages), and a simple voice-first product creation journey: record/enter voice description, take/add product photo, AI understanding into structured fields, photo enhancement preview, fair price range with simple explanation, cultural heritage story/metadata, review and artisan approval. Include a visible transparent offline-first experience: offline indicator, queued changes count, saved locally messaging, sync when online, conflict-safe status. Build demo-ready realistic UI and seeded content across: Home assistant dashboard, Create Listing flow, Catalog, Orders, Messages/AI buyer reply approval, Bulk Opportunities with AI negotiation recommendation and explicit final-approval action, Cluster/SHG collective showcase, Learn with gamified digital literacy lessons/badges, and Profile/settings. The assistant should be voice-accessible in UI. Use large touch targets, minimal typing, clear simple cards, warm Indian craft-inspired visual system, professional accessibility and responsive desktop preview. Emphasize outcome metrics and positioning as an offline-first virtual business manager that lets artisans create, price, market, negotiate, and sell in their own language. Use mock interactions/data where AI/integrations are simulated, but make flows convincingly interactive. Include a buyer-facing marketplace discovery preview only as a secondary surface. Build the full prototype now.
